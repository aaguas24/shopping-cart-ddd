# Requisitos No Funcionales

## RNF-01: Lenguaje de Programación
La aplicación debe desarrollarse en Java con Spring Boot.

## RNF-02: Gestor de Dependencias
Debe usar Maven para la gestión del proyecto.

## RNF-03: Base de Datos
La base de datos debe ser H2 en memoria.

## RNF-04: Arquitectura
La arquitectura debe estar organizada por capas y paquetes.

## RNF-05: Mantenibilidad
El proyecto debe ser mantenible y fácil de extender.

## RNF-06: ORM
Debe usar JPA/Hibernate para persistencia.

## RNF-07: Formato de Respuesta
La API debe responder en formato JSON.

## RNF-08: Testing
Debe contar con pruebas unitarias para entidades y casos de uso.

## RNF-09: Convenciones de Código
Debe seguir buenas prácticas de naming en Java.

## RNF-10: Configuración
La configuración debe estar centralizada.

## RNF-11: Ejecutabilidad
Debe ser compatible con ejecución local desde IDE o terminal.

## RNF-12: Escalabilidad
El sistema debe estar preparado para escalar en nuevas funcionalidades sin romper la arquitectura.
