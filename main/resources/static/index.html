Catálogo inicial de la API

Esta página vive en src/main/resources/static/index.html y Spring Boot la sirve automáticamente desde el mismo puerto del API. No requiere controlador, Thymeleaf ni una ruta adicional.

Abrir portada Abrir H2 Ver catálogo con Thymeleaf
Endpoints

URIs principales

  • POST /categoria/ — registrar categoría
  • POST /producto/ — registrar producto + inventario
  • GET /h2-console — consola H2
Negocio

Códigos de error

  • 400 — validaciones de entrada
  • 409 — excepciones de negocio
  • 500 — persistencia / infraestructura
Catálogos

Valores disponibles

  • EstadoProducto: ACTIVO, INACTIVO, AGOTADO
  • Moneda: PESO, DOLAR, EURO

Si quieres abrir esta página directamente, usa http://localhost:8080/. También queda disponible http://localhost:8080/index.html.
